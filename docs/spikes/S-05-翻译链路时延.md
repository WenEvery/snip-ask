## 3 云端实测（DeepSeek，2026-11-05）

### 3.1 凭据与模型

`GET /models`（Key 运行时传入）返回可用模型：`deepseek-flash`（输入模态 `text,image`）、`deepseek-v4-pro`（`text`）。
按产品默认与 Lead 口径选用 **`deepseek-flash`**；`base_url=https://api.deepseek.com`，`stream=true`。
云端测量期为网络调用，机器上仍有其他 agent 负载（实测前后 CPU 负载 **77%→80%**），但耗时为服务端主导，影响已记录。

### 3.2 方法

`python scripts/spikes/s05_s06/bench_translate.py --runs 20 --warmup 2 --stream`：
每次请求记录 HTTP 状态、首字节（响应头）、**首 token（TTFT）**、**流结束总耗时**、`usage`（含 reasoning_tokens）、输出字符数；
统计 P50/P95/max；按「首字 ≤1.5s」与「总耗时 ≤1.5s」两个口径分别判定。

### 3.3 默认配置（产品默认行为，thinking 开启）

| 指标 | P50 | P95 | max | min | mean |
| --- | --- | --- | --- | --- | --- |
| **TTFT（首 token）** | **3,470.57 ms** | **4,591.45 ms** | 4,632.21 ms | 2,679.52 ms | 3,486.90 ms |
| **总耗时（流结束）** | **4,053.49 ms** | **5,146.49 ms** | 5,211.59 ms | 3,239.99 ms | 4,049.70 ms |
| 首字节（响应头） | 83.76 ms | 132.83 ms | 163.21 ms | 59.52 ms | 94.68 ms |

- n=20，失败 0，HTTP 200 22/22（含 warmup）；prompt_tokens=492，completion_tokens **525–887**，其中
  **reasoning_tokens 384–736**；译文输出 706–744 字符。
- **判定：首字口径 FAILED（P95 4.59s > 1.5s）；总耗时口径 FAILED（P95 5.15s > 1.5s）。**
- 原因：`deepseek-flash` 默认先输出 reasoning（思考）再输出译文，首字被思考时间推高；译文本身生成 ~150 token。

### 3.4 关闭 thinking（产品网关设计中的 `thinking:{"type":"disabled"}`）

请求体追加 `{"thinking":{"type":"disabled"}}`（`SNIPASK_BENCH_EXTRA_JSON` 透传；该字段正是
`llm_gateway.rs TODO(real)` 第 3 条设计），同参数重测 20 次：

| 指标 | P50 | P95 | max | min | mean |
| --- | --- | --- | --- | --- | --- |
| **TTFT（首 token）** | **613.66 ms** | **865.00 ms** | 876.17 ms | 346.10 ms | 620.37 ms |
| **总耗时（流结束）** | **1,512.64 ms** | **1,754.03 ms** | 1,781.67 ms | 1,191.72 ms | 1,498.94 ms |
| 首字节（响应头） | 78.32 ms | 115.39 ms | 143.70 ms | 61.41 ms | 83.74 ms |

- n=20，失败 0，HTTP 200 22/22；prompt_tokens=466（其中 cache 命中 256），completion_tokens **147–151**（**无 reasoning tokens**），
  译文输出 724–729 字符；译文完整可读（样例：`Boxed AI is a screen word-capture and screenshot Q&A tool: press Ctrl+Q ...`）。
- **判定：首字口径 DONE（P95 0.87s ≤1.5s，P50 0.61s）；总耗时口径 FAILED（P95 1.75s >1.5s，P50 1.51s 略超）。**
  即：按产品 README 的「快速模式首字 ≤1.5s」口径达标；若产品要求「完整译文总耗时 ≤1.5s」则不达标（差 ~0.25s，可由流式/限长/缓存优化）。

### 3.5 thinking 参数与 reasoning token 对照（解释差异）

| 变体（2 次 smoke，除注明外） | TTFT 首字 P50/P95 | 总耗时 P50/P95 | reasoning_tokens | 结论 |
| --- | --- | --- | --- | --- |
| 默认（thinking 开） | 3,486.90 / 4,591.45 ms | 4,053.49 / 5,146.49 ms | 384–736 | 思考推高首字 |
| `reasoning_effort=low` | 3,188.3 / 3,413.1 ms | 3,875.5 / 4,043.6 ms | 仍 309–512 | 参数对 DeepSeek 无效（未降思考） |
| `effort=low` | 3,979.1 / 4,194.5 ms | 4,561.6 / 4,801.1 ms | 仍思考 | 无效 |
| `reasoning_effort=none`（1 次 smoke） | 846.0 ms | — | 0 | 有效，但非 OpenAI 标准参数名 |
| **`thinking:{"type":"disabled"}`**（20 次正式） | **613.66 / 865.00 ms** | 1,512.64 / 1,754.03 ms | **0** | **有效，产品设计已预留该开关** |

结论：**DeepSeek 默认 thinking 是云端首字指标的头号风险**；必须由网关显式传 `thinking:{"type":"disabled"}`
（或选择非思考模型）才能满足「快速模式首字 ≤1.5s」。`reasoning_effort/effort` 不生效，不要依赖。

### 3.6 复跑命令


| 指标 | P50 | P95 | max | min | mean |

| 端到端总耗时 | **11,759.50 ms** | **21,836.86 ms** | 23,824.70 ms | **9,886.40 ms** | 13,557.94 ms |
| prefill（服务端） | 3,007.81 ms | 3,775.71 ms | 3,939.19 ms | 2,559.72 ms | 3,067.07 ms |
| decode（服务端） | 8,461.49 ms | 18,201.95 ms | 19,874.95 ms | 7,317.78 ms | 10,480.67 ms |
| tok/s | 17.56 | 19.81 | 20.50 | 7.50 | 15.81 |

## 6 结果汇总与阈值对比

| 链路 | 阈值 | 实测 | 判定 |
| --- | --- | --- | --- |
| **云端首字（默认 thinking）** | ≤1,500 ms | P50 3,470.57 / P95 4,591.45 ms | **FAILED** |
| **云端总耗时（默认 thinking）** | ≤1,500 ms | P50 4,053.49 / P95 5,146.49 ms | **FAILED** |
| **云端首字（thinking 关闭）** | ≤1,500 ms | **P50 613.66 / P95 865.00 ms** | **DONE** |
| 云端总耗时（thinking 关闭） | ≤1,500 ms | P50 1,512.64 / P95 1,754.03 ms | **FAILED（差 ~0.25s）** |
| 本地 1.8B（CPU） | ≤8,000 ms | P50 11,759.50 / P95 21,836.86 / 最快 9,886.40 ms | **FAILED** |
| 极小 0.5B 时延（CPU，产品提示词） | ≤8,000 ms | P50 3,781.74 / P95 4,128.48 ms | **DONE（质量 FAILED：中文复述）** |
| **极小 0.5B + 精简提示词（200 字）** | ≤8,000 ms | **P50 3,091.83 / P95 3,209.41 ms** | **DONE（质量一般但可用）** |
| **极小 1.5B + 精简提示词（200 字）** | ≤8,000 ms | **P50 6,443.38 / P95 6,723.41 ms** | **DONE（质量更好）** |

**关键结论**：
1. 产品 README 的「快速模式首字 ≤1.5s」在 **DeepSeek + `thinking:disabled`** 下成立（P95 0.87s），
   但默认 thinking 会把首字推到 4.6s（P95）→ 网关必须显式关闭思考。
2. 「完整译文总耗时」口径在云端最快也 ~1.5–1.8s（P50 1.51s / P95 1.75s），处于阈值边缘；
   若产品要求总耗时达标，需要限制输出/流式呈现或换更快的非思考模型。
3. 本地 1.8B CPU 明确不达标；极小 0.5B 时延达标但质量不可用。

## 7 处置建议

1. **云端网关（最高优先）**：按 `llm_gateway.rs TODO(real)` 的第 3 条，对 DeepSeek 请求显式携带
   `thinking:{"type":"disabled"}`（供应商不支持则忽略），并保持 `stream:true` 以首字口径验收；关闭思考后
   首字 P95 0.87s、总耗时 P95 1.75s，满足「快速模式首字 ≤1.5s」。
2. **两口径口径统一**：验收指标建议明确为「首字 ≤1.5s」，同时在事件流中记录总耗时与 token；
   若要求完整译文 ≤1.5s，则当前云端（~1.5–1.8s）需再优化（限 max_tokens / 提示词瘦身 / 非思考模型）。
3. **本地翻译策略**：1.8B Q4 CPU 不达标（P95 21.8s），定位「离线兜底、慢路径」，UI 须流式并标注慢；
   默认云端。若要离线可用 ≤8s，建议 GPU offload（RTX 4060 可容纳 1.1GB Q4，预期 <2s，待排期实测）或专用小模型。
4. **极小模型选型（item3）**：Qwen2.5-0.5B 时延好（P95 4.13s、0.55 GiB、加载 1.34s）但**不做翻译**；
   若产品要「极小模型快速可用」，应选择**专用翻译小模型**（opus-mt-zh-en）或做提示词/微调适配后再测质量，
   不要仅凭时延把它作为翻译后端。
5. **S-13 资源降档输入**：1.8B 常驻 2.05–2.10 GiB（Private 1.11 GiB）；0.5B 仅 0.55 GiB（Private 0.23 GiB）。
   `idleUnloadSec=600` 需应用层实现（llama-server 无空闲卸载能力）。
6. **manifest 修正**：`resources/models.manifest.json` 的 ModelScope URL 404、sha256 为占位；
   本报告给出真实文件名、大小、sha256（1.8B 与 0.5B），供 S-08 更新。

## 10 极小模型候选复核（2026-11-05，task-13）

背景：0.5B 在**产品 `translate.md` 提示词**下 10/10 输出中文原文（复述），不能作为极小档推荐。本节复核
「换提示词能否救 0.5B」并补测 1.5B 候选（同一 llama-server、`-t 16 -ngl 0`、`temperature=0.2`）。

### 10.1 Qwen2.5-0.5B-Instruct Q4_K_M × 3 种提示词 × 2 个样例

样例：200 字产品文案；30 字短句「请把这份报告在周五之前发给所有参会人员，谢谢。」；每格 3 次（warmup 0），
判定「是否真的翻译」用自动 CJK 占比（<20% 且非空即视为译文）+ 人工看样例。

| 提示词变体 | 样例 | 端到端 P50 / P95 | 输出 tokens | 是否翻译 | 质量样例 |
| --- | --- | --- | --- | --- | --- |
| 产品 `translate.md`（现状） | 200 字 | 3,659.83 / 3,718.63 ms | 125 | **否（中文复述，CJK 79.5%）** | 输出原文 |
| 产品 `translate.md` | 30 字 | 1,426.33 / 1,428.40 ms | 16 | **否（CJK 91.3%）** | 输出原文 |
| **极简指令** | 200 字 | **3,091.83 / 3,209.41 ms** | 140–155 | **是（CJK 0%）** | `The AI is a screen selection tool for taking words and screenshots: press Ctrl+Q ...`（可读，质量一般） |
| **极简指令** | 30 字 | **396.79 / 420.43 ms** | 14–15 | **是（CJK 0%）** | `Please send this report to all the attendees by Friday. Thank you.` |
| 极简 + 1 few-shot | 200 字 | 778.69 / 815.19 ms | 19 | **否（只复述了 few-shot 例子）** | `Example:\nChinese: The weather is nice today....`（忽略正文，不可用） |
| 极简 + 1 few-shot | 30 字 | 481.77 / 519.10 ms | 14–18 | 是 | `Please send this report to all participants by Friday. Thank you.` |

**结论：0.5B 可以用，但必须换掉产品 `translate.md` 提示词**——极简指令「将下面的中文翻译成英文，只输出译文：」
即可让它真正翻译；few-shot 对 200 字反而有害（只输出示例）。0.5B + 极简提示词：200 字 P95 **3.21s**、30 字
P95 **0.42s**，内存/加载沿用 §5（0.51–0.55 GiB、1.34s），质量「一般但可用」（个别专名/句式生硬，需 UI 标注）。

### 10.2 Qwen2.5-1.5B-Instruct Q4_K_M（兜底候选，已下载并核对）

- 来源 ModelScope `Qwen/Qwen2.5-1.5B-Instruct-GGUF` / `qwen2.5-1.5b-instruct-q4_k_m.gguf`：
  **1,117,320,736 B / 96.83s / 11.5 MB/s**，SHA256 `6a1a2eb6d15622bf3c96857206351ba97e1af16c30d7a74ee38970e434e9407e` 已核对。
- 极简指令，200 字：warmup 2 + 10 次，**P50 6,443.38 / P95 6,723.41 / max 6,894.49 ms**（≤8s DONE）；
  prefill P50 707.7ms、decode P50 5,710.67ms、**25.66 tok/s**、146 token；冷加载 **1,444.5 ms**；
  常驻 WorkingSet **1.67 GiB**（Private 0.88 GiB），峰值 1.70 GiB；0 失败。
- 极简指令，30 字：P50 727.51 / P95 761.09 ms，`Please send this report to all attendees before Friday. Thank you.`
- 质量样例（200 字）：
  `Select AI is a screen-to-text and screenshot question-and-answer tool: Press Ctrl+Q to invoke the selection box, select text or images on the screen, and release the mouse to pop up the action menu...`
  —— 语法通顺、偶有「Select AI」等直译；明显优于 0.5B（0.5B 亦能翻但更生硬）。

### 10.3 候选对比与推荐

| 候选 | 200 字 P95 | 30 字 P95 | 常驻内存 | 冷加载 | 质量 | 建议 |
| --- | --- | --- | --- | --- | --- | --- |
| Qwen2.5-0.5B Q4 + 产品提示词 | 4.13s | 1.43s | 0.55 GiB | 1.34s | **不可用（复述）** | 淘汰 |
| **Qwen2.5-0.5B Q4 + 极简提示词** | **3.21s** | **0.42s** | **0.55 GiB** | 1.34s | 一般但可用 | **推荐为「极小/轻量档」默认**（省内存、快） |
| Qwen2.5-1.5B Q4 + 极简提示词 | 6.72s | 0.76s | 1.70 GiB | 1.44s | 较好 | 质量优先时的「标准本地档」或极小档升级项 |

**推荐**：本地极小档 = **Qwen2.5-0.5B-Instruct Q4_K_M + 极简翻译指令**（P95 3.21s ≤8s，内存 0.55 GiB）；
若 UI 需要更稳的译文质量，用 **Qwen2.5-1.5B-Instruct Q4_K_M + 极简指令**（P95 6.72s，仍 ≤8s，内存 1.70 GiB）。
两者都**不能用产品 `translate.md` 提示词**（0.5B 会复述；1.8B/云端不受此影响）。

**需要同步改的地方**：
1. **manifest**：新增/替换极小模型条目——`qwen2.5-0.5b-instruct-q4_k_m.gguf`（491,400,032 B，
   sha256 `74a4da8c…a9db`）与 `qwen2.5-1.5b-instruct-q4_k_m.gguf`（1,117,320,736 B，sha256 `6a1a2eb6…407e`，
   ModelScope `Qwen/Qwen2.5-*.5B-Instruct-GGUF`）；不要只写 0.5B 而仍用产品提示词。
2. **UI 文案**：极小档描述改为「本地轻量翻译（0.5B，质量一般、离线可用）」，并提示「专业/长文建议云端」；
   不要把 0.5B 宣传为与云端同等质量。
3. **提示词路由**：本地模型档走「精简翻译提示词」，云端/1.8B 走 `translate.md`；在 `prompt_engine` 或
   translator 中按模型选择模板（建议新增 `resources/prompts/translate_minimal.md` 以保持模板可覆盖）。
