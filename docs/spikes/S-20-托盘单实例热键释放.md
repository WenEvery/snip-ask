## 步骤

1. `applab start --owner app-runtime --wait-sec 300`（复用既有便携数据；`--reset` 会清空引导状态，本项不需）；
   main webview 安装 `tray:action` 事件监听与未捕获异常监听；
2. **第二实例 ×10**：每轮先 `window_hide main`（确保「唤起」可观测）→ 记录窗口列表基线 →
   `spawn(.verify/applab/app/snip-ask.exe)` 直接启动第二个进程 → 轮询进程数直到第二进程退出（≤8s）→
   等 600ms 读窗口列表与事件 → 断言「进程数=1、原 pid 存活、主窗口可见、`singleInstance` 事件 +1」；
3. **托盘探测**：`s20_tray.ps1 -Action showicon`（`WM_USER_SHOW_TRAYICON(6005)` 把图标从溢出区移到通知区域）→
   `-Action status`（宿主窗口/Shell 注册/UIA 命中）→ 把鼠标移到屏幕底边唤出自动隐藏任务栏 →
   `-Action click`（UIA 定位 + 真实鼠标点击，重试 3 次，检测原生 `#32768` 菜单是否可见）；
4. **暂停 / 恢复热键 ×3**：`config_patch` 绑 `togglePause=Ctrl+Alt+P` → 辅助进程先探测 `Ctrl+Q`（应为 1409）→
   `press_hotkey.ps1 Ctrl+Alt+P` 暂停 → 辅助进程注册 `Ctrl+Q`（应成功）→ 再按一次恢复 → 辅助进程再次 1409；
   同时读 `hotkey_probe` IPC 结果；结束时还原 `togglePause=""`；
5. **退出释放 ×5**：每轮辅助进程探测 `Ctrl+Q`（应 1409）→ `app_quit` IPC 正常退出 → 轮询进程归零 →
   辅助进程注册 `Ctrl+Q`（应成功）→ 重新 `applab start` 进入下一轮；
6. 收尾：`applab stop`；确认 `Get-Process snip-ask` = 0；`Ctrl+Q` 最终可注册（探测后立即注销，无泄漏）；
   还原便携配置（`togglePause=""`）。

## 处置

- 单实例行为、退出释放热键、暂停保留 `togglePause` 三项按实测写入实现边界；
- 托盘菜单项与动作映射固化在 `app/tray.rs`，本轮以「同一处理函数 + 等价入口」核验，未发现动作映射错误；
- 环境事实记录（供后续自动化）：本机**任务栏自动隐藏** + 新托盘图标默认在**溢出区** → 托盘图标 UIA 元素只在
  溢出浮层出现；`Shell_NotifyIconGetRect` 在任务栏隐藏时返回屏幕外坐标；`TrackPopupMenu` 需前台激活，
  `PostMessage` 触发不弹菜单（与 S-04 一致）。
