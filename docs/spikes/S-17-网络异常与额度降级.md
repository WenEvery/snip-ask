## 处置

- 错误码映射与 fallback 语义可写入实现边界；`provider_test` 作为设置页/引导页「测试连接」的唯一真实网络入口已稳定；
- `config_patch.providers` 是**数组整体替换**（非按 id 合并）：本轮首次用 `{id,baseUrl}` 局部对象 patch，
  导致 provider 的 `model/caps` 被清空、设置页出现「模型名不能为空」内联校验（未写配置即被拦截）；
  已改为传完整 provider 对象并写入遗留 L-3（建议在接口文档标注该语义）；
- 建议在真实网关接入时统一实现 429/5xx 退避重试（≤2 次），当前只给用户可操作重试入口（S-17 遗留 L-2）。
