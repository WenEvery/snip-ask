## 3 实现说明

### 3.1 分层与可测性

真实下载核心是**与 Tauri 无关的纯函数**（`model_manager.rs`）：

```rust
pub async fn download_with_resume<F>(
    client: &reqwest::Client, urls: &[String], dest: &Path,
    expected_size: u64, expected_sha256: &str,
    cancel: &AtomicBool, retry: &RetryPolicy, on_progress: F,
) -> Result<DownloadOutcome, DownloadError>
where F: FnMut(DownloadProgress);
```

`ModelManager` 只负责：状态机（queued → downloading → verifying → installed/failed/cancelled）、
`download:progress` 节流（≤200 ms，loaded 事件侧钳制单调）、`download:state` 推送、`.installed` 标记写入。
因此集成测试可直接用本地 `TcpListener` HTTP server 验证，不需要 `AppHandle`。

### 3.2 行为要点

- **临时文件**：`<models_dir>/<id>/<file>.partial`，大小/哈希全部通过后 `rename` 为最终文件；
  `.installed` 只由 manager 在成功后写（空文件，兼容既有 `scan_installed`），`.partial` **不计入** installed。
- **断点续传**：`.partial` 存在 → 发 `Range: bytes=<len>-`；206 校验 `Content-Range` 起点，续写；
  服务端 200（忽略 Range）→ 丢弃断点从头写；416 且断点 ≥ 期望大小 → 对现有文件算哈希走校验。
- **重试与镜像回退**：单 URL 独立重试（默认 3 次，200 ms 起 ×2 指数退避，封顶 2 s）；
  5xx/408/429/网络错误重试；404 与其他 4xx 立即切换下一个镜像；全部失败 → `failed`（保留 `.partial` 供下次续传）。
- **流式 SHA256**：首块起逐块 `update`；续传时先把已有前缀**流式重读**喂给 hasher（进程被杀后 hasher 状态丢失，
  重读是恢复正确性的关键），因此无需下载完成后再全文件二次扫描。
- **校验失败处置**：大小/SHA256 不符 → 删除 `.partial` → **整轮重下一次**（最多 2 轮）→ 仍失败则 `failed`。
- **取消**：`download:cancel` 置 `AtomicBool`，chunk/重试/哈希读前后检查；返回 `Cancelled` 时**保留 `.partial`**，
  状态 `cancelled`，下次下载自动续传。
- **HTTP 客户端**：UA=`snip-ask/<version>`、connect timeout 15 s、整体 timeout 60 min；
  实测 ModelScope/Aliyun CDN **对无 User-Agent 请求返回 403**，UA 必须设置（见 §6.3）。
- **骨架模式**：`ModelManager` 新增 `skeleton_mode: Arc<AtomicBool>`（默认 `true`）与
  `set_skeleton_mode(bool)`；为 `true` 时走原骨架下载（每 100 ms 4%、空 `.installed`），代码逐字保留。
