# 框选 AI · 文档索引

本目录是「框选 AI（Snip Ask）」的设计与使用文档入口。安装包内的 `docs\` 会随附本页、
[`自定义指南.md`](自定义指南.md)、`LICENSE`、`NOTICE`、`SECURITY.md`、`PRIVACY.md`，
应用内「设置 → 自定义与关于 → 安装文档」可直接打开。

> 契约（命令/事件/配置字段）的唯一事实来源是 [`接口契约.md`](接口契约.md)（**契约 v6**，v1.0.1）。

## 阅读顺序建议

1. 第一次接触：`../README.md` → `自定义指南.md`；
2. 参与开发：`实施架构.md` → `接口契约.md` → `开发指南.md`；
3. 做验收/复现：`技术验证清单.md` → `spikes/README.md` → `release/README.md`；
4. 想改：`自定义指南.md` §3–§10。

> 历史文档（可行性研究报告 / 概要设计说明书 / 追加需求可行性研究）保留立项时的方案与结论，
> 其中「自动更新」「更新通道」「遥测」等已被 [ADR-0008](adr/0008-remove-auto-update.md)、v1.0.0（去自动更新）
> 与 v1.0.1（不收集任何用户信息）决策移除，以 [`CHANGELOG.md`](../CHANGELOG.md) 与本目录现行文档为准。
