## 1 验收口径（不可放宽）

| 项 | 口径 |
| --- | --- |
| 样本 | **3 名未接触过本产品的新用户**（非本项目开发者、未看过引导页/设计稿、未参与实现） |
| 任务 | 从首次启动开始，完整走完 6 步引导；不填 API Key、不下载模型（阈值不含模型下载，与清单一致） |
| 计时 | 从**窗口首次出现**（引导第 1 步可见）到**第 6 步点击「完成并进入」且主界面出现**；录屏打点，精确到 0.1s |
| 阈值 | 首次完成最小配置 **≤ 3 分钟（180s）** |
| 卡点 | 记录「停顿 > 5s」「点错后回退」「需要提问」「找不到下一步/跳过」；阻塞性困惑 = 0 |
| 环境 | applab 便携实例（`--reset` 首次启动）；真实网络（无 Key 时可复现受限模式）；单屏或双屏均需记录 |
| 记录 | 每人 1 份：录屏文件 + 计时表 + 卡点表 + 原话摘录；走查后 5 分钟简短访谈（哪一步最困惑/最想跳过） |

## 2 准备（每次走查前）

```powershell
# 1) 独占应用 + 清空便携数据（模拟首次启动）
node scripts/spikes/applab/applab.mjs reserve --owner s19-walkthrough --minutes 30
node scripts/spikes/applab/applab.mjs start --owner s19-walkthrough --wait-sec 600 --reset

# 2) 让引导窗口可见（应用默认 visible:false；走查必须真人可见）
node scripts/spikes/applab/applab.mjs eval --window main --js "window.__TAURI_INTERNALS__.invoke('window_show',{window:'main'})"

# 3) 打开录屏（Windows 11：Win+G 或 Xbox Game Bar；录屏文件放 .verify/spikes/S-13-S-17-S-19-S-20/raw/s19/human/）
# 4) 主试只做两件事：计时、记录；不提示操作，不替用户点击（除安全相关）
```

走查结束：

```powershell
node scripts/spikes/applab/applab.mjs stop --owner s19-walkthrough
```

## 3 主试操作手册（不干预原则）

1. 只说一句任务：「请用这个应用完成一次初次设置，让它可以用来翻译/搜索；过程中请尽量按你自己的想法操作。」
2. 不主动指路；用户问「点哪个」时回答「你觉得呢？」；用户卡住 **> 30s** 才给最小提示，并记为卡点。
3. 计时点：T0 = 引导第 1 步完全渲染（`第 1 / 6 步` 可见）；T1 = 第 6 步「完成并进入」点击成功且主界面出现。
4. 每步记录：进入时间、离开时间、是否回头、是否打开「跳过引导」、是否打开「上一步」。
5. 结束时用 3 个问题收尾：①哪一步最困惑？②哪里想直接跳过？③3 分钟内完成了吗？
